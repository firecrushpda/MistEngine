# Mist-Engine
C++ DirectX 11 Engine

## 关于本项目
本项目基于 [Medo-Osman/Marble-Engine](https://github.com/Medo-Osman/Marble-Engine)（Marble Engine v1.1）开发。
在原项目的基础上更名为 Mist Engine，并进行代码重构与功能扩展。原项目的版权归原作者所有。

## 本プロジェクトについて
本プロジェクトは [Medo-Osman/Marble-Engine](https://github.com/Medo-Osman/Marble-Engine)（Marble Engine v1.1）をベースに開発しています。
元のプロジェクトを Mist Engine に改名し、コードのリファクタリングと機能拡張を行っています。元プロジェクトの著作権は原作者に帰属します。

## Features
* Deferred Renderer
* HDR Pipeline
* ACES Tonemapping
* Adaptive Exposure
* PBR Pipeline
* Bloom
* SSAO
* ImGui
* Procedural Sky
* Simple Day/Night Cycle
* Shadow Mapping
* Volumetric Sky-Light(Sun or Moon) Scattering
* Assimp
* Scene/Map Saving and Loading
* Particle System
* Lens Flare
